# Plain Kubernetes exercise

Before using Helm, write equivalent manifests here: namespace.yaml,
api-deployment.yaml, worker-deployment.yaml, api-service.yaml,
configmap.yaml, redis-service.yaml, redis-statefulset.yaml.
Start in a separate namespace named queue-lab-manual.
Do not apply manual manifests into the Terraform-owned namespace.
The Helm chart is the reference implementation if you get stuck.
